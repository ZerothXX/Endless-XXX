## 自行训练

在项目使用的 DL 环境中运行根目录 train_reviewed.py（可直接在 IDE 运行）。此入口固定角色 37，按 config.CHARACTER_PRESETS["37"] 读取分辨率和步数，当前为 640 / 600；不是之前的 512 / 200 试验配置。

每次创建 output/experiments/retrain_时间戳/，保存 weights、logs、curves、源码快照和 manifest。它从底模新建 LoRA，不是断点续训；禁止自动预处理原始数据，不覆盖默认权重，也不会自动提升新权重。运行输出 AUDIT_DIR 后，训练日志见其中 run.log。

训练完成后，先检查图片效果，再把 config.LORA_WEIGHT_PATH 指向该次 weights/37_final.safetensors 的绝对路径，运行 test.py。无需拷贝覆盖旧权重。best 由训练参考诊断损失选择，并非视觉效果最佳的保证。

直接运行旧 train.py 仍使用原输出目录；为保留历史权重，请使用本次提供的 train_reviewed.py。
