# Endless-XXX · FLUX.2 研究

[中文](README.md) · [English](README.en.md)

本分支简要介绍基于 FLUX.2 的角色视觉迁移研究，面向人物、动物与物品。当前仍处于实验阶段。

## 当前方法

以 **FLUX.2 Klein 4B 官方蒸馏模型**为生成核心，暂以**无 LoRA 的固定多图参考**为主线：同一角色使用 2–3 张完整参考图，与待转换图片共同输入模型。

| 输入类型 | 方法 |
|---|---|
| 人物 | 目标图在前，随后输入完整角色参考；通过提示词约束姿势与手持道具。 |
| 物品 | 使用完整角色参考，通过提示词引导配色、纹样与材质的迁移。 |
| 动物 | 完整角色参考参与生成，同时由 Qwen3-VL 读取同组参考图，补充角色设计描述。 |

本地推理采用 NF4 4bit 量化、BF16 计算，蒸馏模型使用 4 步采样、CFG 1。

## 研究方向

已探索角色 QLoRA 微调、参考图顺序与注意力权重、局部设计板，以及先理解角色再生成设计描述等方法；这些作为候选方向保留。
